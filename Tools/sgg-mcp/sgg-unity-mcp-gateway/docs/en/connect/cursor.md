# Connect Cursor


Cursor can use the Gateway through the stdio shim or through a deliberately configured remote HTTP MCP endpoint.

## Recommended Local Path

1. Start Unity and the Gateway from `SGG/Unity MCP/MCP Window`.
2. Open `Setup -> MCP Connection`.
3. Copy the Cursor/stdio configuration generated by the installed package.
4. Review the command and environment placeholders.
5. Save it in the Cursor MCP configuration location used by your installation.
6. Reload Cursor's MCP servers.

The stdio shim is an adapter to the already-running HTTP Gateway. It is not a second Unity MCP server.

Generic shape:

```json
{
  "mcpServers": {
    "sgg-unity-mcp": {
      "command": "sgg-unity-mcp-gateway",
      "args": [
        "stdio-shim",
        "--config",
        "%LOCALAPPDATA%/SGG/UnityMcpGateway/config/gateway.json"
      ]
    }
  }
}
```

The Unity window may generate a more explicit installed-runtime command. Prefer the generated form when the CLI is not on `PATH`.

## Explicit URL Form

```json
{
  "mcpServers": {
    "sgg-unity-mcp": {
      "command": "sgg-unity-mcp-gateway",
      "args": [
        "stdio-shim",
        "--url",
        "http://127.0.0.1:27182/mcp",
        "--token-env",
        "SGG_UNITY_MCP_TOKEN"
      ],
      "env": {
        "SGG_UNITY_MCP_TOKEN": "<set-in-a-local-secret-store-or-process-environment>"
      }
    }
  }
}
```

Do not commit a real local token. Prefer a process environment or client secret store.

## Remote HTTP

Use a native remote MCP entry only when Cursor's current version supports the required transport and you intentionally configured the Gateway listener.

Non-loopback access requires token authentication, allowed origins, and local firewall controls. The Unity Bridge itself is not exposed; only the Gateway endpoint is configured in the client.

## Validate

Run:

```text
sgg_unity_projects
sgg_unity_describe(project="<project-id>", selector="commands")
sgg_unity_call(project="<project-id>", command="compile.status", args_json="{}", mode="wait")
```

If Cursor does not advertise MCP elicitation, `ask`-gated calls return `confirmation_required`. Use the pending-approval fallback from [Permissions and approvals](../guides/permissions.md); never add a self-approval MCP tool.

## Exact Tool Names

The top-level names are:

```text
sgg_unity_projects
sgg_unity_describe
sgg_unity_call
sgg_unity_batch
sgg_unity_job
sgg_unity_logs
```

Unity commands such as `scene.hierarchy` are values inside `sgg_unity_call.command`, not additional top-level tools.
